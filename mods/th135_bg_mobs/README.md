## 二、 架构与设计原则 (Zero Regression & Precision)

1. **原版字节码委托包装架构 (`bg01_base.nut` ~ `bg11_base.nut`)**：
   - 彻底避免手工反编译官方 3D 引擎可能带来的语法错位（如除法指令、相机偏置、动态粒子缺失等），直接无损提取 TH15.5 官方编译字节码作为底层 base；
   - 顶层由极简、100% 纯小写 ASCII 的包装脚本执行 `::manbow.CompileFile("..._base.nut", this)`，并安全挂接 `this.UpdateMob()` 与 3D Billboard 渲染管线。
2. **跨代码页等长 ASCII 原位映射（彻底杜绝 Windows CP936 乱码）**：
   - 所有原始日文文件名在磁盘上均被映射为同等字节长度的小写 ASCII 唯一文件名（如 `m_00001.png`），内部 `.pat` 二进制与 `.msh` / `.mat` 材质文件完成原位字节级对齐替换；
   - 在任何中文简体 (CP936)、日文 (CP932) 或英文 Windows 环境下加载均 100% 稳定，永不发生贴图黑块或缺失。
3. **严格不动清单**：
   - `bg12` ~ `bg46` 等《深秘录》(TH14.5) 与《凭依华》(TH15.5) 原创新场景 100% 保持官方原版未动；
   - 游戏系统逻辑、对战判定、人物平衡性、背景音乐音效、系统 UI 0 字节修改。

## 四、 启用与配置方式

### 方式一：原生 Mod 加载器免解包直读（推荐）
游戏目录已配备基于 `winmm.dll` 的原生 Mod 加载器。只需在游戏根目录的 `mod_loader.ini` 中启用：
```ini
[Mods]
th135_bg_mobs=1
```
直接双击运行官方原版 `th155.exe`，加载器通过虚拟文件系统 (VFS) 自动拦截重定向，无需解包、不修改官方 pak、不污染原始 `data/`。

### 方式二：手动同步与注入
若需要同步文件或向正在运行的游戏热注入：
```powershell
# 同步文件至游戏 mods/ 目录
python d:\programme\155rl\mods\th135_bg_mobs\apply_bg_mobs.py --sync-only

# 动态热注入运行中的 th155.exe (翻转红黑树 Pak 索引并补丁门禁)
python d:\programme\155rl\mods\th135_bg_mobs\apply_bg_mobs.py
```
